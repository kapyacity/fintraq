Google Sheets Setup Guide

1. Create Sheet: Open sheets.new to create your spreadsheet.
2. Open Apps Script: In Google Sheets menu, click Extensions > Apps Script.
3. Paste Code: Erase any default code and paste the code from scripts/google-sheets-audit.js in this project.
4. Deploy Web App: Click Deploy > New deployment, select type Web app.
5. Permissions: Set Execute as: Me, Who has access: Anyone.
6. Connect: Copy the Web app URL, paste it in FinTraQ Settings, and click Save!
